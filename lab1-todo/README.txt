Как запустить программу:
1. Откройте проект в Visual Studio.
2. Нажмите клавишу F5 или кнопку "Запуск".
3. Откроется окно "Мои задачи".
4. Файл tasks.json создастся автоматически при первом добавлении задач.
Файл с задачами сохраняется в папке bin\Debug\net8.0-windows\tasks.json (или рядом с exe-файлом).

Чек-лист:
- Основные задания: всё выполнено (модели, операции, ошибки, сохранение).
- Дополнительные задания: реализован фильтр, сортировка, поиск, подсветка цветом и проверка IsOverdue().

Как устроен проект:
- Program.cs — точка входа.
- MainForm.cs — интерфейс и обработка кликов.
- TodoList.cs — логика фильтрации, сортировки, сохранения в JSON.
- TodoItem.cs — модель одной задачи с приватными полями и методами.
